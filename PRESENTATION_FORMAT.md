# Organization Presentation Format Guide

**For Claude:** When presenting organizations to the user, use these clean formats.

---

**Democracy & Governance Foundations:**

   Global democracy advocacy, human rights monitoring

2. **National Endowment for Democracy** - https://ned.org/jobs
   Grants for democratic movements worldwide

## Key Principles:

✅ **Use numbered lists** for easy reference
✅ **Bold organization names** for quick scanning
✅ **One-line descriptions** (5-10 words max)
✅ **Direct career page URLs** (not homepages)
✅ **Group by category** when presenting 15+ orgs
✅ **Include count** in headers (e.g., "12 organizations")

❌ **Avoid:**
- Long paragraphs about each org
- Excessive details
- Generic homepage URLs
- Mixing different formats in one response
